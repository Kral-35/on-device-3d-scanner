## 🛠️ Technical Information (For the Curious)

If you're interested in what makes this app tick, here's a simple explanation:

The app uses three main technologies working together:
1. **Depth Anything 3:** This technology estimates how far each pixel in your photos is from the camera. It creates a "depth map" for each photo.
2. **react-native-executorch:** This is a powerful tool that lets the app run complex AI models efficiently on your phone without slowing it down.
3. **TypeGPU:** This handles the heavy 3D graphics processing, turning all the depth information into a smooth, interactive 3D model.

Together, these technologies create what's called "gaussian-splat" rendering—a state-of-the-art technique that makes your captured photos look like a fully 3D scene, rather than just a flat collection of images.
